# Test audio

Audio for rendering Smartscope's screenshots and demo video with real material, made by
Claes Lanng for this purpose.

- `Smartscope Audio-Visual Test - Kick 1.wav`: the kick, one hit on every beat. Goes into
  sidechain 1.
- `Smartscope Audio-Visual Test - Bass 1.wav`: the bass, with sidechain ducking already
  applied, so it gets out of the way of each kick. Goes into the main input.

Both are 4 bars at 128 BPM (7.5 s), 44.1 kHz stereo, and start on the downbeat at the
same sample. The kick is 16-bit, the bass 24-bit.
